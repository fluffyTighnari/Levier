- 从 `ToolDef.config_json` 读取模板配置。
- 渲染 method/url/headers/body。
- 受限重试与调用的超时归属。
- 响应大小限制。
- 与 P7-52/P7-53 的 Invoker 路由、幂等链路打通。

## 3. 配置

`config_json` 示例：

```json
{
  "method": "POST",
  "url": "https://api.example.com/search?q={{urlquery .args.q}}",
  "headers": {
    "Authorization": "Bearer ${secret:search_token}",
    "Content-Type": "application/json"
  },
  "body": "{\"query\":{{json .args.q}}}",
  "max_response_bytes": 1048576,
  "retries": 2,
  "retry_backoff_ms": 100
}
```

| 字段 | 默认 | 约束 |
|---|---|---|
| `method` | `GET` | GET/POST/PUT/PATCH/DELETE/HEAD/OPTIONS |
| `url` | 必填 | 渲染后仅允许 http/https |
| `headers` | 空 | header 名必须合法；渲染为空则省略 |
| `body` | 空 | Go `text/template` |
| `max_response_bytes` | 1 MiB | 1 B – 8 MiB |
| `retries` | 0 | 0 – 3 |
| `retry_backoff_ms` | 100 | 0 – 5000 |

配置使用 `DisallowUnknownFields`，拼错字段直接报配置错误。

## 4. 模板

数据：

```json
{
  "args": {"q": "..."},
  "args_json": "{\"q\":\"...\"}",
  "run_id": "...",
  "app_id": "...",
  "invocation_id": "...",
  "tool_name": "..."
}
```

- `{{.args.q}}` 取参数。
- `{{json .args}}` 序列化。
- `{{urlquery .args.q}}` URL 转义。
- `missingkey=error`：缺键直接失败，不静默渲染 `<no value>`。
- `url`、`headers`、`body` 均可模板化；`method` 为静态配置。

## 5. 请求与重试

- 请求体未配置时不发送 body；有 body 且未设置 `Content-Type` 时默认 `application/json`。
- 超时由 Invoker 的 `context.WithTimeout` 控制，executor 不自行叠加超时。
- 重试条件：
  - 网络错误；
  - HTTP 5xx；
  - HTTP 429。
- 4xx（429 除外）不重试。
- 退避为 `retry_backoff_ms × 第几次重试`，并响应上下文取消。
- 最终超时返回 `context.DeadlineExceeded`，由 Invoker 映射为 `TOOL_TIMEOUT(retryable=true)`。

## 6. 响应

2xx 返回统一 JSON 信封：

```json
{"status": 200, "body": {"ok": true}}
```

- body 是合法 JSON 时原样嵌入。
- 非 JSON body 以字符串返回。
- 非 2xx 映射：

| 状态 | code | retryable |
|---|---|---|
| 4xx（非 429） | `HTTP_4XX` | false |
| 429 | `HTTP_4XX` | true |
| 5xx | `HTTP_5XX` | true |
| 超过响应上限 | `RESPONSE_TOO_LARGE` | false |
| 配置/模板/参数错误 | `TOOL_EXEC_ERROR` | false |
| 网络错误（重试耗尽） | `TOOL_EXEC_ERROR` | true |

错误消息包含截断到 512 字节的响应片段。

## 7. 配置存储与密钥

- `tool_defs.config_json` 保存 global executor 配置。
- 注册时只校验 JSON 语法；具体 executor 配置在首次执行时校验。
- 解析工具时展开 `${secret:name}`，明文只存在于内存；数据库保留占位符。
- local tool 不使用 `config_json`。

## 9. 风险与未完成

| 项 | 影响 | 处理 |
|---|---|---|
| 允许访问任意 http/https 地址 | 存在 SSRF 风险 | 配置由管理员写入；生产需 egress 白名单 |
| 注册时不校验 executor 配置 | 错误配置在首次调用才暴露 | P7-55 统一配置校验 |
| 不支持自定义 CA/客户端证书 | 私有 TLS 端点受限 | 后续配置扩展 |
| 默认跟随重定向 | 可绕过初始 URL 的主机限制 | 生产可加 redirect 策略 |
| 错误响应片段进入消息 | 可能包含上游敏感内容 | 已截断到 512 字节；后续可配置 |
| 请求体没有大小限制 | 大参数会占用内存 | 协议层已有消息上限，后续可加 executor 限制 |
| 没有执行器指标 | 延迟/状态码不可观测 | P8 |
| `builtin:webhook` 未实现 | 预注册 URL 场景不可用 | P7-55 |
