## 3. 关键决策

- HTTP DTO 独立于 proto/DB，避免把 gRPC 类型泄漏到 App API。
- `CreateRunRequest` 不接收 `api_key`；模型凭据由 middleware 解析。
- `POST /runs` 的幂等键仍走 `Idempotency-Key` header，不进 body。
- WS 客户端消息用接口 + `ParseClientMessage` 统一解析；unknown/bad protocol 直接拒绝。
- v1 WS 握手为 `{"type":"hello","protocol":1}`，可省略。
- `subscribe` 带 `last_attempt/last_seq`，与事件复合主键一致。
- `local_tool_result` 必须带 correlation_id + invocation_id；`ok` 与 `error` 互斥。
- OpenAPI 3.1 作为契约说明骨架，P1-12 后再补完整 schema/示例。
