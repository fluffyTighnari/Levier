## 3. 一键命令

```sh
make m1-e2e
```

前置：

- PostgreSQL 可连接
- `MIDDLEWARE_DATABASE_URL` 由 `.env.local` 或环境提供
- `harness/.venv` 已安装依赖

脚本执行：

```text
go run ./cmd/migrate
bin/middleware
python -m middleware_harness
curl POST /api/v1/runs
curl GET /api/v1/runs/{id}
curl GET /api/v1/runs/{id}/events
psql run_tasks / run_events snapshot
SIGTERM cleanup
```
