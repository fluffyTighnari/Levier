## 1. 目标

实现非 MCP 工具的 RuntimeChannel 闭环，以及独立的 `mcp_runtime` 进程：

- Harness 通过 `ToolCallRequest/Result` 调用 local/global 工具。
- Harness 通过 `McpRuntimeClient` 调用独立 MCP Runtime。
- Runtime 负责 MCP 连接、stdio 子进程、session、`tools/list`、`tools/call`。
- Middleware 和 Harness 都不持有 MCP 连接。

## 3. 架构

```text
Harness
  ├─ ToolBridge ── ToolCallRequest/Result ──► Middleware Tool Gateway
  └─ ToolRouter
       ├─ McpRuntimeClient ── Unix socket JSON-RPC ──► mcp_runtime
       └─ ToolBridge

mcp_runtime
  ├─ JSON-RPC server
  ├─ SessionManager
  └─ SdkConnector ── stdio / SSE / streamable_http ──► MCP servers
```

- `mcp_runtime` 不在 `harness/` 内，也不在 Go Middleware 内。
- Harness 不导入 MCP SDK。
- Middleware 不保存 MCP session、连接或 stdio 进程。

## 4. 关键设计

### 4.1 JSON-RPC 契约

本地方法：

```text
mcp.health() -> {status, version, sessions}
mcp.open(binding) -> {session_id, tools[]}
mcp.call(session_id, tool_name, arguments_json, timeout_ms)
mcp.close(session_id)
```

- v1 默认 Unix domain socket。
- `--stdio` 用于单客户端调试。
- JSON-RPC 错误包含 `code`、`message`、`data.retryable`。
- Runtime 按连接清理 owner session，避免 Harness 断线后泄漏。

### 4.2 MCP session

- 每个 Run 的每个 binding 打开独立 session。
- 每个 session 有独立 `asyncio.Lock`，会话内调用串行。
- session 关闭时回收 stdio 子进程、SSE/HTTP 连接。
- `allowed_tools` 为空表示全部；非空时在 `tools/list` 和调用阶段都限制。
- 工具名：`mcp__<server_name>__<tool_name>`；自定义 namespace 缺少 `__` 时自动补齐。
- server_name 做字符清洗，避免非法工具名。

### 4.3 MCP 工具结果

- 单文本 block：`result_json` 直接是文本。
- 多 block 或 structured content：`result_json` 是 JSON 对象。
- `CallToolResult.is_error` 映射为 `ok=false`、`error.code=TOOL_EXEC_ERROR`。
- Runtime 超时映射为 `TOOL_TIMEOUT`，可重试。
- 连接/初始化失败映射为 `MCP_CONNECT_FAILED` 或 `MCP_CONNECT_TIMEOUT`。

### 4.4 非 MCP 工具

`ToolBridge`：

- 发 `ToolCallRequest`，`correlation_id` 关联请求。
- 等待 `ToolCallResult`，按 `invocation_id` 保留幂等键。
- 超时返回 `TOOL_TIMEOUT`，通道断开返回 `CHANNEL_UNAVAILABLE`。

`ChannelClient.request()`：

- 按 `msg_id` 建 future。
- 收到 `tool_call_result` 时优先解析 correlation，不交给 RunManager。
- 连接关闭/客户端停止时，所有 pending 请求失败。

### 4.5 Harness 配置

```yaml
mcp_runtime:
  socket: "/tmp/middleware-mcp.sock"
```

- 为空表示不启用 MCP Runtime；MCP 工具不可用，但不阻塞 Run。
- 环境变量：`HARNESS_MCP_RUNTIME_SOCKET`。

## 6. 风险与未完成

| 项 | 影响 | 处理 |
|---|---|---|
| SSE/streamable_http 未做真实 server 集成 | 真实网络行为未覆盖 | 后续加本地 HTTP MCP server 测试 |
| Runtime 单连接请求串行处理 | 多 session 并发时可能排队 | v1 工具调用串行；后续按 session 并发 |

| Runtime 崩溃后 session 丢失 | 进行中的 MCP 工具失败 | Harness 返回 `MCP_RUNTIME_UNAVAILABLE`；重试由策略层决定 |
