## 3. 关键决策

- Claim 使用 `FOR UPDATE SKIP LOCKED` + `UPDATE ... RETURNING`，不阻塞其他 worker。
- Claim 只领取 `PENDING AND available_at <= now() AND attempt < max_attempts`。
- 每次 Claim `lease_token++`、`attempt++`，TTL 默认 30s。
- `Extend/Ack/Nack/Fail` 必须匹配 `task_id + owner + token`。
- Ack 清空 lease、置 DONE。
- Nack 根据 attempt 决定 PENDING 或 DEAD；写入 `last_error` 和 `available_at`。
- Fail 直接 DEAD。
- 终态任务上的 lease 操作返回 `ErrTaskTerminal`；owner/token 不匹配返回 `ErrLeaseLost`。
- 并发 Claim 由 `SKIP LOCKED` 保证不重复。

## 4. 验证

```sh
MIDDLEWARE_TEST_POSTGRES=1 go test -count=1 -v -timeout 60s ./internal/workflow
make lint
make test
make build
make proto-check
```

结果：

- Claim → Extend → Ack 成功，租约到期时间延长。
- 第二次 Claim 返回 `ErrNoTask`。
- 旧 token Extend/Ack 返回 `ErrLeaseLost`。
- Nack 后回到 PENDING，attempt 保留；再次 Claim attempt++。
- 达到 max_attempts 后 Nack 进入 DEAD。
- Fail 进入 DEAD。
- 8 个并发 Claim 无重复任务。
- 真实 PostgreSQL 16.15 全部通过；默认 `make test` 跳过 DB 测试。
- `make lint/test/build/proto-check` 全绿。
