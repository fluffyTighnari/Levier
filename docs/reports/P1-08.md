## 3. 关键决策

- 一个对称 `Envelope` 同时承载双向消息；不拆 Request/Response 类型。
- `attempt` / `lease_epoch` 只放在 `Envelope`，不嵌套重复。
- `Event.seq` 仅持久化事件递增；ephemeral 固定 0。
- `TaskAssign.mcp_bindings` 使用 `McpBinding`，包含 `allowed_tools` 与 `namespace`。
- `Hello.running_runs` 使用 `RunningRun{run_id, lease_epoch}`。
- `Checkpoint` 的 attempt 来自 `Envelope.attempt`，与 `event_seq_watermark` 组成复合 watermark。
- buf lint 保留 STANDARD，仅豁免：
  - 对称 Envelope 的 RPC 命名规则；
  - enum value 前缀规则（设计/生成客户端使用短名）。
