## 1. 目标

把“靠人工 grep”变成默认护栏：

```text
make lint
→ fmt-check
→ go vet
→ secrets-check
```

## 2. 改动

### 2.1 扫描器

新增 `scripts/check_secrets.py`：

```text
只扫描 git-tracked 文件
排除 gen/、harness/src/gen/、docs/reports/artifacts/、workflow_engine/
```

规则：

```text
sk-* OpenAI/DeepSeek 形态
Bearer <长 token>
postgres://<user>:<password>@...
DEEPSEEK_API_KEY=<value>
明显的 inline api_key/secret/token 字面量
```

占位符放行：

```text
change-me
${...}
<...>
[REDACTED]
example
```

失败时只打印 `file:line: rule`，不打印密钥内容。

自带自检：

```sh
python3 scripts/check_secrets.py --self-test
```

### 2.2 配置占位

- `config.example.yaml` DSN 改为 `change-me:change-me`
- `.env.example` DSN 改为 `change-me:change-me`
- `internal/config/config_test.go` 的测试 DSN 也改为占位，避免扫描误报

### 2.3 Makefile

```make
lint: fmt-check vet secrets-check

secrets-check:
    python3 scripts/check_secrets.py
```

## 4. 风险

| 项 | 影响 | 处理 |
|---|---|---|
| 正则误报 | 正常文档/测试被拦 | 使用窄规则 + 占位符放行；失败只报路径行号 |
| 只扫 tracked 文件 | 本地 `.env` 内容不检查 | `.env` 已被 gitignore；共享/提交前仍建议轮换真实 key |
| 不检查 git 历史 | 历史泄露不会发现 | 本次不做历史重写；如怀疑泄露需轮换 |
| 不自动 redacting handler | 日志边界仍靠显式调用 | 现有 `RedactValue/RedactMap`；后续按需接入 |
