## 3. 关键决策

- Go 使用本地 `protoc-gen-go`、`protoc-gen-go-grpc`，`paths=source_relative`，输出到 `gen/`。
- Python 使用 BSR remote plugins，输出到 `harness/src/gen`；运行时把该目录加入 `PYTHONPATH`。
- 生成物提交到仓库；CI 重新生成后 `git diff --exit-code`，防止 proto 与 stub 漂移。
- `buf breaking` 以 `main` 为基线；P1-08 之后只允许新增字段/消息。
- 生成文件遵守生成器头注释，不手工添加项目头；符合 `docs/CODE_STYLE.md` 的例外规则。
- Go 插件版本固定在 CI：buf `v1.75.0`、protoc-gen-go `v1.36.12`、protoc-gen-go-grpc `v1.6.2`。
