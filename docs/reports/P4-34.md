## 3. API

### POST /api/v1/runs

请求：

```json
{
  "app_id": "app-1",
  "runtime": "normal",
  "strategy": {"name": "echo", "params": {}},
  "input": [{"role": "user", "content": "hello"}],
  "model": {"provider": "anthropic", "model": "claude-test"},
  "timeouts": {"run_ms": 1800000, "tool_ms": 60000}
}
```

行为：

- Bearer 鉴权。
- `app_id` 必填。
- 校验 runtime/strategy/model/input/timeouts。
- `Idempotency-Key` 可选：
  - 同 key + 同 body → 返回已有 Run。
  - 同 key + 不同 body → `409 IDEMPOTENCY_CONFLICT`。
- 创建 `runs` 行，状态 `queued`。
- 新 Run 入队 `RUN_DISPATCH`。
- 返回 `202`：

```json
{"run_id":"...","status":"queued","ws_url":"/api/v1/ws","ws_token":""}
```

### GET /api/v1/runs/{run_id}

返回 `RunView`：

- run_id / app_id
- runtime / strategy
- status / attempt
- session_id / trace_id
- created_at / updated_at

不存在返回 `404 RUN_NOT_FOUND`。

### GET /api/v1/runs/{run_id}/events

查询参数：

- `after_attempt`
- `after_seq`
- `limit`，默认 100，最大 1000

返回：

```json
{
  "events": [],
  "caught_up": true,
  "next_attempt": 1,
  "next_seq": 1
}
```

### 鉴权

```yaml
http:
  bearer_token: "change-me"
```

- `Authorization: Bearer <token>`。
- 未配置 token 时不启用鉴权（本地开发）。
- `/healthz` 不需要鉴权。

## 4. 入口接线

`cmd/middleware` 现在同时启动：

- HTTP API `http.addr`
- gRPC RuntimeService `grpc.addr`
- Control worker pool
- DaemonHub

SIGTERM 时：

- 停止 workflow worker
- 停止 Control
- 关闭 Hub
- `http.Server.Shutdown`
- 优雅停止 gRPC
- 超时强制 Stop

## 5. 验证

```sh
go test ./internal/httpapi -v
go test ./internal/runstore -v
MIDDLEWARE_TEST_POSTGRES=1 go test ./...
make lint
make build
make proto-check
make contract-check
```

手工验证：

```sh
curl -X POST http://127.0.0.1:8080/api/v1/runs \
  -H 'Authorization: Bearer change-me' \
  -H 'Content-Type: application/json' \
  -d '{"app_id":"app-http-test","runtime":"normal","strategy":{"name":"echo"},"input":[{"role":"user","content":"hello"}],"model":{"provider":"anthropic","model":"claude-test"},"timeouts":{"run_ms":10000,"tool_ms":5000}}'
```

结果：

- 返回 202 `run_id` / `queued`。
- `GET /runs/{id}` 返回 queued RunView。
- `GET /runs/{id}/events` 返回空事件列表。
- 未带或错误 token 返回 401。
- 同 key 同 body 返回同一 Run，不重复入队。
- 同 key 不同 body 返回 409。
- 队列失败返回 500。
- 实际启动 `bin/middleware` 后 HTTP/gRPC 均监听，SIGTERM 退出码 0。
- Go 全量测试、lint、build、proto、contract 全绿。

## 6. 风险与未完成

| 项 | 影响 | 处理 |
|---|---|---|
| 只有静态 Bearer token | 没有 App 级 API key 校验 | P5 Register |
| `app_id` 必填但不校验 App 是否存在 | 可创建孤立 Run | P5 |
| CreateRun 与入队非同一事务 | 入队失败时留下 queued Run | P5/D13 补事务 |
| 幂等重复请求不补入队 | 首次入队失败后可能卡住 | 后续补 task 检查/重入队 |
| `ws_token` 为空 | WS 鉴权未接 | P7 |
| 没有 cancel/session/admin apps 端点 | OpenAPI 中部分路径未实现 | P5/P7 |
| 没有请求限流 | 公开接口可能被刷 | P8 |
| 没有分页总数/游标语义 | 只按 limit 返回 | P5/P7 |
| 事件查询先 GetRun 再 ListEvents | 多一次查询 | 可接受 |
| HTTP 未接 TLS | 内网/反代终止 | P8/P10 |
