## 3. 关键设计

### 3.1 provider 契约

```python
async def complete(
    messages: Sequence[Message],
    tools: Sequence[ToolSpec],
    model: ModelConfig,
    *,
    on_delta: DeltaCallback | None = None,
) -> LLMResponse
```

- `ModelConfig` 从 `TaskAssign.model` 转换，包含 provider/model/api_key/base_url/params。
- `on_delta` 每收到一段文本就回调，由 ReAct 策略转成 ephemeral `MESSAGE_DELTA`。
- provider 不感知 Run/Envelope；只做模型协议适配。

### 3.2 Anthropic 请求

- 默认端点：`https://api.anthropic.com/v1/messages`
- 默认版本头：`anthropic-version: 2023-06-01`
- `stream: true`
- `max_tokens` 默认 4096，可由 `model.params.max_tokens` 覆盖。
- 支持 `temperature`、`top_p`、`top_k`。
- system 消息合并为顶层 `system`。
- assistant 工具调用转换为 `tool_use` block。
- tool 结果转换为 `tool_result` block，并合并为同一条 user 消息。
- MCP 工具在 v1 仍然只以普通工具清单传入；MCP 连接由 P3-29 的 provider 处理。

### 3.3 流式解析

- 支持 SSE `message_start`、`content_block_start`、`content_block_delta`、`message_delta`、`message_stop`。
- 文本：累积并回调 `on_delta`。
- 工具：按 content block index 累积 `input_json_delta`。
- usage：合并 `input_tokens`、`output_tokens` 及其他整数字段。
- 非流式 JSON 响应也支持，便于测试和代理场景。

### 3.4 错误映射

| 情况 | code | retryable |
|---|---|---|
| 429 / `rate_limit_error` | `RATE_LIMITED` | 是 |
| 408 / `timeout_error` | `TIMEOUT` | 是 |
| 5xx / `overloaded_error` / `api_error` | `PROVIDER_UNAVAILABLE` / `PROVIDER_ERROR` | 是 |
| 401 / 403 / `authentication_error` / `permission_error` | `AUTH_FAILED` | 否 |
| 400 / 404 / `invalid_request_error` | `BAD_REQUEST` | 否 |
| 网络/传输失败 | `PROVIDER_UNAVAILABLE` | 是 |
| 非法 JSON / 非法工具参数 | `BAD_RESPONSE` / `BAD_REQUEST` | 否 |

`LLMError` 字段：`code`、`retryable`、`status`。ReAct 将其写入 `ERROR` 事件。

### 3.5 事件

- `MESSAGE_DELTA`：ephemeral，`seq=0`，data 为 `message_id`、`delta`、`step`。
- `MESSAGE_COMPLETED`：持久，复用同一个 `message_id`。
- `USAGE`：持久，直接使用 provider usage 字段。
- `ERROR`：持久，包含 `code`、`message`、`retryable`。

### 3.6 入口装配

- `__main__` 根据 `daemon.strategies` 构建 `StrategyRouter`。
- 当前可用：`echo`、`react`。
- 未知策略在启动时报配置错误。
- `react` 使用 `AnthropicProvider`，API key 来自每次 `TaskAssign.model`，不从本地配置读取。

## 5. 风险与未完成

| 项 | 影响 | 处理 |
|---|---|---|
| 未用真实 Anthropic API 验证 | 真实网络/认证路径未覆盖 | 用真实 key 做一次手工 smoke；CI 仍用假 transport |
| `UrllibTransport` 未做压力测试 | 高并发下线程/队列行为未量化 | 后续加入 provider 并发测试与连接池替代 |
| retryable 只分类，不自动重试 | 策略层暂不重试 LLM 错误 | 后续在 Control/策略层决定重试 |
| 只有 Anthropic | OpenAI 未实现 | 后续按需增加 provider |
| `max_tokens` 默认 4096 | 长输出可能被截断 | 通过 `model.params.max_tokens` 配置 |
| usage 未单独落库 | 仅作为事件发送 | MW 事件落库后由 P4/P9 处理 |
| 没有 provider 级指标 | 无法观察延迟/错误率 | 后续接入 observe |
