## 1. 目标

在全面链路调试前固定认证与授权边界：

- 生产默认关闭 legacy bearer。
- Admin 接口只接受 `admin_token`，不回落 legacy bearer。
- App key 只能访问自己的 run/events/cancel/session。
- ws_token 与 local_tool_result 的边界测试。
- 密钥存储、secret 占位符、日志脱敏。
- M1 E2E 改用 App API key，不再依赖 legacy bearer。

## 3. 认证矩阵

| 主体 | 凭据 | 行为 |
|---|---|---|
| App → MW | `Authorization: Bearer <app_api_key>` | 只能访问自身资源 |
| Admin → MW | `Authorization: Bearer <admin_token>` | 管理 App、可跨 App 查询 |
| Legacy bearer | `http.bearer_token` | 仅当 `allow_legacy_bearer=true` 才生效 |
| Daemon → MW | Hello `daemon_id + auth_token` | 预分配 token |
| WS | `ws_token` | 绑定 app_id、TTL 10 分钟 |

关键变化：

- `allow_legacy_bearer` 默认 `false`。
- `isAdmin` 不再在 `admin_token` 为空时回落到 `bearer_token`。
- `config.example.yaml` 不再提供 legacy bearer。
- M1 E2E 通过：

```text
POST /admin/apps
  → 若 App 已存在且 api_key 为空 → POST /admin/apps/{app_id}/rotate-key
  → 后续 runs/status/events 全部使用 App API key
```

## 4. App 作用域

已覆盖：

| 场景 | 结果 |
|---|---|
| App 查询自己的 Run | 200 |
| 其他 App 查询 Run | 404 |
| 其他 App 查询 events | 404 |
| 其他 App cancel | 404 |
| 其他 App 查询 session | 404 |
| 其他 App 读 session events | 404 |
| 其他 App 使用他人 ws_token | 拒绝连接 |
| Admin 查询任意 Run | 200 |
| 创建 Run 时 app_id 与 App key 不一致 | 403 |

## 5. 工具与 WS 边界

沿用并纳入安全基线：

- ACL 拒绝返回 `TOOL_DENIED`，不泄露 global 工具存在性之外的信息。
- local 工具只能解析到属主 App。
- `local_tool_result`：
  - correlation 不匹配 → `LOCAL_TOOL_CORRELATION_MISMATCH`
  - 未知 invocation → `LOCAL_TOOL_UNKNOWN`
  - 其他 App 伪造 → `LOCAL_TOOL_FORBIDDEN`
  - 重复结果幂等忽略
- ws_token：
  - TTL 10 分钟
  - 过期拒绝
  - app_id 不匹配拒绝
  - 可用 App key 重签

## 6. 密钥与脱敏

| 项 | 实现 |
|---|---|
| App API key | 库存 SHA-256 hash，明文只返回一次 |
| App key rotate | 旧 key 立即失效 |
| MCP/global tool 配置 | `${secret:name}` 占位符，数据库保留占位符 |
| 日志 | 不打印 Authorization/api_key/ws_token/secret |
| 脱敏工具 | `observe.RedactValue/RedactMap` |
| 指标标签 | 不含 token/secret/header |
| M1 证据 | `app.json`/`app_rotate.json` 的 api_key、`create.json` 的 ws_token 均脱敏 |

## 9. 未完成与风险

| 项 | 影响 | 处理 |
|---|---|---|
| legacy bearer 仍可显式开启 | 运维误配可能放宽权限 | 生产配置审计；后续删除 |
| `/metrics` 未鉴权 | 指标可被读取 | 网关/内网限制 |
| 没有速率限制 | 暴力尝试/刷接口 | P8 压测/网关 |
| 没有 CORS | 浏览器直连受限 | 网关或后续中间件 |
| 没有安全审计表 | 无法追溯管理操作 | P8/P9 |
| 没有 TLS/mTLS | 依赖网络层 | 部署层 |
| MCP 凭据仍进入执行进程内存 | v1 已知风险 | ADR 已记录；v2 凭据代理 |
| key 轮换无宽限期 | rotate 立即失效 | 当前设计如此，客户端需即时切换 |
