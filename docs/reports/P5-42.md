## 3. Tool 目录

### local ToolDef

- 随 App 注册全量替换。
- `ReplaceLocalTools(appID, tools)`：
  - 删除不在新列表中的 local tools
  - 按 `(app_id, name)` upsert
  - `version++`
- `schema_json` 必须是合法 JSON。
- 默认 `timeout_ms=60000`。

### global ToolDef

- `UpsertGlobalTool`。
- 必须有 `executor_ref`。
- `acl_json`：
  - `NULL` = 所有 App 可见
  - 数组 = 仅白名单 App 或 `*`
- 全局工具不能与 local 同名冲突；解析时 local 优先。

### ResolveTool

```text
local(app_id, name) → 命中返回
否则 global(name) → ACL 检查 → 命中返回
否则 not found
```

local 遮蔽 global。

## 4. MCP 目录

- `UpsertMCPServer`：stdio/sse/streamable_http。
- `SetAppMCPRefs`：按 name 引用 MCP server，替换 App 的引用集合。
- MCP server 不存在时拒绝。
- `AssembleTaskMaterials` 只产出连接描述，不建立连接。

### 命名空间

```text
mcp__<sanitized_server_name>__
```

### allowed_tools

- `allowed_tools_json` 为空 = 全部
- 非空 = 白名单
- 白名单写入 `McpBinding.allowed_tools`
- 未授权 MCP 工具不会出现在绑定白名单中

## 5. Secret 解析

支持：

- `EnvSecretResolver`
  - `${secret:github_token}` → `MIDDLEWARE_SECRET_GITHUB_TOKEN`
- `FileSecretResolver`
  - JSON 文件 `{ "github_token": "..." }`

解析范围：

- MCP `command`
- `url`
- `env` 值
- `headers` 值

测试确认：

- 占位符被替换为真实值
- 缺失 secret 时组装失败
- `TaskMaterials` 不打印密钥
- G5 快照中的密钥已脱敏

## 6. AssembleTaskMaterials

```text
local tools
  + global tools（ACL 通过）
  + local 遮蔽 global
  + app MCP refs → McpBinding
```

产出：

```go
TaskMaterials{
    Tools:       []ToolMaterial,
    MCPBindings: []MCPMaterial,
}
```

Control 转成：

- `TaskAssign.tools`
- `TaskAssign.mcp_bindings`

TaskAssign 不携带连接对象。
