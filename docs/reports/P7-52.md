## 3. 路由

```text
ToolCallRequest
  → ResolveToolDecision(app_id, tool_name)
      ├─ denied   → TOOL_DENIED
      ├─ not found→ TOOL_NOT_FOUND
      └─ found
           ├─ mcp__*       → TOOL_NOT_FOUND（由 MCP Runtime 处理）
           ├─ local        → AppHub.CallLocalTool
           └─ global       → ExecutorRegistry(executor_ref)
```

## 4. 错误码

| 情况 | code | retryable |
|---|---|---|
| 未知工具 | `TOOL_NOT_FOUND` | false |
| ACL 拒绝 | `TOOL_DENIED` | false |
| App 断线 | `APP_UNREACHABLE` | true |
| 本地/全局超时 | `TOOL_TIMEOUT` | true |
| executor 未注册 | `TOOL_NOT_FOUND` | false |
| 执行异常 | `TOOL_EXEC_ERROR` | false |
| 请求非法 | `BAD_REQUEST` | false |

## 5. 超时

优先级：

1. `ToolCallRequest.timeout_ms`
2. `ToolDef.timeout_ms`
3. 默认 60s

- local：传给 AppHub pending call。
- global：`context.WithTimeout`。

## 6. Control 接线

Hub 收到 `ToolCallRequest` 后：

```text
Control.HandleToolCall
  → GetRun 取 app_id
  → Invoker.Invoke
  → ToolCallResult
  → protocol.NewResponse
  → Hub.Send
```

`ToolCallResult.correlation_id` 回填 `ToolCallRequest.msg_id`。

当前 global executor 注册表为空，P7-54 再接 `builtin:http`。
