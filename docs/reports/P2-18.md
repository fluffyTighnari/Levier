## 3. 关键决策

- `CancelRun` 只取消 `PENDING/LEASED`，终态任务不受影响。
- `CancelTask` 只取消指定 run + task_type。
- LEASED 任务取消时 `lease_token++`，并清空 owner/expiry。
- 旧 owner 的 `Extend/Ack/Nack/Fail` 返回 `ErrLeaseLost`。
- 正常终态（Ack 成功）不递增 token，重复 Ack 返回 `ErrTaskTerminal`。
- 取消原因为空时使用默认 `cancelled`。
- 取消是幂等的：重复取消返回 0 个受影响任务。

## 4. 验证

```sh
MIDDLEWARE_TEST_POSTGRES=1 go test -count=1 -v -timeout 90s ./internal/workflow
make lint
make test
make build
make proto-check
```

结果：

- PENDING 任务取消后为 CANCELLED；同 run/type 可再次入队。
- LEASED 任务取消后 lease 清空、token 递增；旧 lease 的四类写入均返回 `ErrLeaseLost`。
- `CancelTask` 不影响其他 task_type。
- Ack 先完成时，CancelRun 返回 0，任务保持 DONE。
- 5 轮 Ack/Cancel 并发：要么 DONE + cancelCount=0，要么 CANCELLED + cancelCount=1 + Ack=ErrLeaseLost。
- 真实 PostgreSQL 16.15 通过；默认 `make test` 跳过 DB 测试。
- `make lint/test/build/proto-check` 全绿。
