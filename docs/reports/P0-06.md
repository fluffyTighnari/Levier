## 3. 关键决策

- 配置默认值集中在 `config.Default()`；YAML 使用 `KnownFields(true)` 拒绝拼写错误。
- env 覆盖只支持显式白名单，避免隐式映射：
  - `MIDDLEWARE_HTTP_ADDR`、`MIDDLEWARE_GRPC_ADDR`、`MIDDLEWARE_DATABASE_URL`
  - `MIDDLEWARE_LOG_LEVEL`、`MIDDLEWARE_LOG_FORMAT`
  - `MIDDLEWARE_*_SHUTDOWN_TIMEOUT`
  - `MIDDLEWARE_WORKFLOW_WORKERS`、`MIDDLEWARE_WORKFLOW_LEASE_TTL`
  - `MIDDLEWARE_WORKFLOW_POLL_INTERVAL`、`MIDDLEWARE_WORKFLOW_MAX_ATTEMPTS`
- `errs` 的 retryable/HTTP 映射直接对应 DESIGN §4.5；`INTERNAL` 默认不可重试，可用 `WithRetryable` 覆盖。
- `clock.Clock` 只暴露 `Now()`，后续 Workflow/Control 依赖接口注入。
- 日志字段常量统一在 `observe`，避免字符串散落。
- `main` 默认读 `config.example.yaml`，可用 `-config` 或 `MIDDLEWARE_CONFIG` 覆盖。
