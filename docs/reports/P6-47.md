## 3. 挂起表

`AppHub.pending`：

```text
invocation_id → { appID, resultChan }
```

`CallLocalTool`：

1. 校验 invocation_id / tool_name
2. 注册 pending
3. 向该 App 所有 WebSocket 连接广播 `local_tool_call`
4. 等待 result / ctx / timeout

`local_tool_call`：

```json
{
  "type": "local_tool_call",
  "msg_id": "...",
  "invocation_id": "...",
  "tool_name": "...",
  "arguments_json": "...",
  "timeout_ms": 60000
}
```

## 4. 结果路由

App 发送：

```json
{
  "type": "local_tool_result",
  "correlation_id": "...",
  "invocation_id": "...",
  "ok": true,
  "result_json": "..."
}
```

`handleWS` 转成 `connection.LocalToolResult`，调用：

```go
appHub.ResolveLocalTool(appID, result)
```

规则：

- 只有对应 App 能 resolve 自己的 invocation
- 第一次结果解除挂起
- 重复结果直接忽略
- 未知 invocation 忽略

## 5. 超时、取消、断线

| 情况 | 行为 |
|---|---|
| `TimeoutMS` 到期 | `ErrLocalToolTimeout`，移除 pending |
| `ctx` 取消 | 返回 `ctx.Err()`，移除 pending |
| App 所有连接断开 | pending 收到 `APP_UNREACHABLE`，移除 |
| `AppHub.Close` | 所有 pending 收到 `APP_UNREACHABLE` |
| 无 App 连接 | 直接 `ErrAppUnreachable` |

## 7. 风险与未完成

| 项 | 影响 | 处理 |
|---|---|---|
| 未接 Gateway | 还没有 ToolCallRequest 进入 AppHub | P7 |
| 结果没有缓存 | 重复调用同一 invocation 不返回缓存 | P7 幂等表 |
| invocation 未绑定 run | 只校验 app，未校验 run 归属 | P7 上下文 |
| 广播到所有 App 连接 | 多连接时可能重复执行 | App 侧幂等 + P7 选择策略 |
| pending 只存内存 | 重启丢失 | P7/P8 |
| 没有本地工具 ACL | 只依赖 App 执行 | P7 |
| 没有并发上限 | 大量挂起占内存 | P7/P8 |
| 没有 cancellation 向 App 下发 | 只能本地移除 pending | P7 |
