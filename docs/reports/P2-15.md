## 3. 关键决策

- 迁移 0002 不重建表，只加约束/索引，保证已有数据可前滚。
- `attempt BETWEEN 0 AND max_attempts`；超限由数据库拒绝。
- `LEASED` 必须有 owner、token、expiry；非 `LEASED` 必须清空 owner/expiry（token 可保留用于 fencing 观察）。
- 新增 `idx_run_tasks_run(run_id, status)` 支持按 Run 取消。
- 新增 `idx_run_tasks_dead(status, updated_at) WHERE status='DEAD'` 支持 DLQ 查询。
- 集成测试使用独立 schema，不污染 `public`。
