## 3. 关键决策

- P3-23 使用 Python 标准库 `dataclasses` + PyYAML 做配置，避免引入 pydantic/pydantic-core 依赖；配置结构简单，后续如果需要复杂校验再评估。
- `SecretToken.__repr__/__str__` 始终显示 `***`；`Settings.summary()` 不包含 token。
- 环境变量覆盖显式列出，不用隐式反射：
  - `HARNESS_MIDDLEWARE_ADDRESS` / `HARNESS_MIDDLEWARE_TLS`
  - `HARNESS_DAEMON_ID` / `HARNESS_DAEMON_AUTH_TOKEN`
  - `HARNESS_DAEMON_RUNTIME_TYPE` / `HARNESS_DAEMON_MAX_CONCURRENT_RUNS`
  - `HARNESS_DAEMON_STRATEGIES` / `HARNESS_DAEMON_LABELS`
  - `HARNESS_LOGGING_LEVEL` / `HARNESS_LOGGING_FORMAT`
- `--check` 只加载/校验配置并输出健康快照后退出。
- 正常运行只等待 SIGINT/SIGTERM；RuntimeChannel 从 P3-24 开始接。
- 日志字段白名单只输出 `daemon_id/run_id/attempt/lease_epoch/strategy/step/invocation_id`。

## 4. 验证

```sh
PYTHONPATH=harness/src/gen:harness/src .venv312/bin/python -m unittest discover -s harness/tests -v
PYTHONPATH=harness/src/gen:harness/src .venv312/bin/python -m middleware_harness \
  --config harness/config.example.yaml --check
make harness-test
```

结果：

- Python 3.12 测试：11 个全部通过。
- `--check`：输出健康快照，退出码 0。
- 正常启动：收到 SIGTERM 后输出 `harness stopped`，退出码 0。
- 非法配置：退出码 1，错误包含路径。
- `make harness-test` 用系统 Python 3.9 也能通过（PyYAML 可用，代码使用 future annotations）。
- 未引入 pydantic/pydantic-core；避免当前网络不可用导致的安装失败。
