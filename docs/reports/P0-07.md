## 3. 关键决策

- 使用 `pgx/v5/pgxpool`，不引入 ORM。
- 迁移文件嵌入 Go 二进制；`schema_migrations` 记录版本；`pg_advisory_lock` 防并发迁移。
- 每条迁移单独事务；失败回滚，不记录版本。
- 测试使用独立 PostgreSQL schema，避免污染 `public`，结束后 `DROP SCHEMA ... CASCADE`。
- `cmd/middleware` 只做连接/健康检查，不自动迁移；迁移由 `cmd/migrate` 显式执行。
- 本地 `.env.local` 覆盖 `MIDDLEWARE_DATABASE_URL`，不提交任何密码。
