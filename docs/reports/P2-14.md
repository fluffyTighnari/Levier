## 3. 关键决策

- TaskType 固定四种：`RUN_DISPATCH`、`RUN_RETRY`、`RUN_TIMEOUT`、`RUN_RECONCILE`。
- 默认 MaxAttempts：dispatch=5，retry/timeout/reconcile=3。
- Task 状态：`PENDING/LEASED/DONE/DEAD/CANCELLED`。
- `Task.Validate` 校验 ULID、run_id、类型、状态、attempt 上限、LEASED 租约完整性。
- `Store` 接口严格对应 ADR-0001：Enqueue/Claim/Extend/Ack/Nack/Fail/Cancel/Reap/Stats。
- Handler 返回 `nil` → Ack；`RetryAfter` → Nack；`Permanent` → Fail；其他错误 → 默认 Nack。
- DeadLetterHandler 只定义契约；P2-20/P6 接入 Control。
