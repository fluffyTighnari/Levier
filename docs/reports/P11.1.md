## 1. 目标

让一个没有接触过项目的人在单机上用一条命令跑通：

```text
PostgreSQL 迁移
→ Middleware
→ Harness
→ App bootstrap / 工具注册 / WebSocket
→ 提交 Run
→ 等待终态
→ 校验事件和工具调用
```

同时把 README 从“空骨架”修正为当前真实状态。

## 3. demo 行为

```text
1. source .env.local / .env
2. make build
3. go run ./cmd/migrate
4. 启动 bin/middleware
5. 等 /healthz
6. 启动 harness
7. 用 Admin token bootstrap 唯一 App
8. 启动 serve.py（注册工具 + 连 WS）
9. 提交 Run
10. 轮询 /api/v1/runs/{id}
11. 拉事件，统计 TOOL_CALL_BEGIN/END、ERROR、最终回答
12. 写 summary.txt
13. 退出时 kill 进程并删除凭据文件
```

模式：

```text
make mvp-demo        echo，不依赖模型
make mvp-demo-react  真实 DeepSeek + counter 工具
```

输出目录：

```text
data/mvp-demo/<stamp>-<mode>/
```

`data/` 已 gitignore；本次证据复制到 `docs/reports/artifacts/P11.1/`。
