- 配置校验。

## 3. 配置

```json
{
  "url": "https://hooks.example.com/events",
  "headers": {
    "Authorization": "Bearer ${secret:hook_token}",
    "X-Event": "{{.tool_name}}"
  },
  "payload": "{\"event\":\"{{.tool_name}}\",\"data\":{{json .args}}}",
  "response_map": {
    "event_id": "body.id",
    "status": "status",
    "first_item": "body.items.0.name"
  },
  "max_response_bytes": 1048576,
  "retries": 2,
  "retry_backoff_ms": 100
}
```

| 字段 | 默认 | 约束 |
|---|---|---|
| `url` | 必填 | 静态 http/https，不允许模板 |
| `headers` | 空 | header 名必须合法；渲染为空则省略 |
| `payload` | 参数 JSON | Go `text/template` |
| `response_map` | 空 | 键非空；路径以 `status`/`body` 开头 |
| `max_response_bytes` | 1 MiB | 0 – 8 MiB |
| `retries` | 0 | 0 – 3 |
| `retry_backoff_ms` | 100 | 0 – 5000 |

`method` 固定为 POST，配置中出现 `method` 会因未知字段报错。`url` 中出现 `{{` 会被拒绝，避免参数改写目标地址。

## 4. 与 HTTP 共用

```text
HTTPConfig ─┐
            ├─► requestSpec ─► executeRequest ─► doRequest
WebhookConfig┘                         │
                                       ├─ 模板渲染
                                       ├─ 状态码判断
                                       ├─ 重试/退避/上下文
                                       └─ 响应大小限制
```

差异只在：

- webhook 固定 POST。
- webhook URL 必须静态。
- 2xx 响应编码：`builtin:http` 使用 `{status, body}`；webhook 有 `response_map` 时只输出映射字段。

## 5. 响应映射

- 路径第一段只能是 `status` 或 `body`。
- 支持对象字段与数组下标：`body.items.0.name`。
- 映射结果是一个 JSON 对象。
- 映射路径缺失、响应不是 JSON 时返回不可重试的 `TOOL_EXEC_ERROR`。
- 未配置 `response_map` 时返回与 HTTP 相同的信封。

示例：

```json
{"status": 200, "body": {"id": "wh-1", "ok": true, "items": [{"name": "a"}]}}
```

配置：

```json
{"response_map": {"event_id": "body.id", "ok": "body.ok", "first": "body.items.0.name", "status": "status"}}
```

结果：

```json
{"event_id": "wh-1", "ok": true, "first": "a", "status": 200}
```

## 6. 重试与错误

- 网络错误、5xx、429 可重试。
- 其他 4xx 不重试。
- 超时由 Invoker 的 context 控制，最终为 `TOOL_TIMEOUT(retryable=true)`。
- 状态码错误沿用 `HTTP_4XX` / `HTTP_5XX`。
- 配置、模板、payload、响应映射错误为 `TOOL_EXEC_ERROR`，不可重试。
- 响应超限为 `RESPONSE_TOO_LARGE`。

## 8. 风险与未完成

| 项 | 影响 | 处理 |
|---|---|---|
| URL 静态但未限制私网地址 | 管理员可配置内网 webhook | 生产需 egress/目标白名单 |
| 没有签名/HMAC 生成 | 接收方无法验证来源 | headers 可用 `${secret:...}` 手动设置，后续可加签名器 |
| 响应映射只支持点路径 | 复杂转换需要额外 executor | v1 范围 |
| 映射路径缺失即失败 | 上游响应结构变化会中断工具 | 由配置方负责；后续可加 optional |
| 注册时不校验 executor 配置 | 首次执行才暴露 | 后续统一注册校验 |
| 不支持自定义 CA/证书 | 私有 TLS 受限 | 后续扩展 |
| 没有执行器指标 | 延迟/状态码不可观测 | P8 |
