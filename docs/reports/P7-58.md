## 3. correlation 校验

`CallLocalTool` 生成 `msg_id` 并保存到 pending：

```json
{
  "type": "local_tool_call",
  "msg_id": "01...",
  "invocation_id": "01...",
  "tool_name": "search",
  "arguments_json": "{}",
  "timeout_ms": 60000
}
```

App 必须回填：

```json
{
  "type": "local_tool_result",
  "correlation_id": "01...",
  "invocation_id": "01...",
  "ok": true,
  "result_json": "..."
}
```

- `correlation_id` 必须等于 pending 的 `msg_id`。
- 不匹配返回 `LOCAL_TOOL_CORRELATION_MISMATCH`，pending 保留，允许 App 用正确 ID 重试。

## 4. 校验与幂等

`ResolveLocalToolChecked` 返回：

| 情况 | 结果 |
|---|---|
| 正确匹配 | `LocalToolResolved` |
| 已完成 invocation | `LocalToolDuplicate` |
| 不存在 | `LocalToolUnknown` |
| 其他 App | `LocalToolForbidden` |
| correlation 不匹配 | `LocalToolCorrelationMismatch` |

- 首次结果解除挂起并写入 completed 缓存（10 分钟，最多 1024 条）。
- 重复结果返回 `LocalToolDuplicate`，不重复投递。
- 未知 invocation 返回 WS 错误 `LOCAL_TOOL_UNKNOWN`。
- 伪造 App 返回 `LOCAL_TOOL_FORBIDDEN`，不删除原 pending。
- `CachedLocalToolResult(appID, invocationID)` 可读取已完成结果，且只对原 App 可见。

## 8. 风险与未完成

| 项 | 影响 | 处理 |
|---|---|---|
| completed 缓存只存单进程 | 多实例重发可能变为 unknown | P8 多实例设计 |
| 缓存 10 分钟 | 超期后的重复结果返回 unknown | 与 invocation 缓存 TTL 对齐，可配置 |
| 结果仍广播到所有 App 连接 | 多连接可能重复执行 | App 侧幂等 + 后续选择策略 |
| pending 只存内存 | MW 重启丢失 | P8 韧性 |
| 没有 local tool 并发上限 | 大量挂起占内存 | P8 |
| 伪造结果只拒绝不断连 | 恶意连接可反复尝试 | P8 安全策略 |
| `run_completed` 可能重复 | 客户端需按 run 幂等 | 已记录 |
