## 3. Schema

### tool_defs

```sql
tool_id, scope(local/global), app_id, name, description,
schema_json, executor_ref, timeout_ms, acl_json, version,
created_at, updated_at
```

约束：

- local 必须有 `app_id`
- global 必须有 `executor_ref` 且 `app_id` 为空
- local 唯一：`(app_id, name)`
- global 唯一：`name`
- `timeout_ms > 0`
- `version > 0`

### mcp_server_defs

```sql
mcp_id, name UNIQUE, transport(stdio/sse/streamable_http),
config_json, allowed_tools_json, created_at, updated_at
```

### sessions

```sql
session_id, app_id, status(active/paused/expired),
current_run_id, checkpoint_blob,
event_attempt, event_watermark,
created_at, updated_at, expires_at
```

复合 watermark：

```text
(event_attempt, event_watermark)
```

索引：

- `(app_id, status)`
- `expires_at WHERE expires_at IS NOT NULL`

### tool_invocations

```sql
invocation_id PRIMARY KEY, run_id, tool_name,
status(in_flight/completed/failed), result_json, error_json,
created_at, completed_at
```

索引：

- `(run_id, created_at)`
- `(status, created_at) WHERE status='in_flight'`

### runs 补充约束

- `attempt >= 0`
- `lease_epoch >= 0`
- `run_timeout_ms > 0`
- `tool_timeout_ms > 0`
- status 枚举：
  - queued / assigned / running / completed / failed / cancelled / timeout
- `(app_id, status)` 索引

### run_events 补充约束

- `attempt >= 1`
- `seq >= 1`
- `(run_id, type, ts_ms)` 索引
