## 3. 状态机

```text
queued
  ├─ assigned（AssignRun）
  ├─ cancelled
  ├─ failed
  └─ timeout

assigned
  ├─ running
  ├─ completed
  ├─ failed
  ├─ cancelled
  └─ timeout

running
  ├─ completed
  ├─ failed
  ├─ cancelled
  └─ timeout

completed / failed / cancelled / timeout
  └─ 终态，不再迁移
```

## 4. AssignRun CAS

```go
type Assignment struct {
    RunID              string
    ExpectedStatus     string
    ExpectedAttempt    int
    ExpectedLeaseEpoch int64
    Attempt            int
    LeaseEpoch         int64
    DaemonID           string
}
```

SQL 条件：

```text
run_id = expected
status = expected_status
attempt = expected_attempt
lease_epoch = expected_lease_epoch
status IN (queued, assigned)
```

成功才写入：

- `status=assigned`
- `attempt`
- `lease_epoch`
- `assigned_daemon_id`
- `assigned_at`

并发分配时只有一个能成功，另一个收到 `ErrRunNotAssignable`。

## 5. Transition CAS

```go
type Transition struct {
    RunID              string
    ExpectedStatus     string
    ToStatus           string
    ExpectedAttempt    int
    ExpectedLeaseEpoch int64
    AttemptDelta       int
}
```

SQL 条件：

```text
run_id = ?
status = expected_status
attempt = expected_attempt
lease_epoch = expected_lease_epoch
status NOT IN 终态
```

成功后：

- `status=to_status`
- `attempt=attempt+attempt_delta`
- `updated_at=now()`

非法迁移在 Go 侧白名单直接拒绝；并发失败在 SQL 无行后返回 `ErrRunNotAssignable`。

## 6. Control 单一写者

Control 现在是唯一状态迁移调用方：

- 调度：`AssignRun`
- `RUN_STATUS running`：`assigned → running`
- 终态事件：`running/assigned → completed/failed/cancelled/timeout`
- 事件先 `AppendEvent`，再 `Transition`

`AppendEvent` 仍然只更新事件水位，不修改 `runs.status`。
