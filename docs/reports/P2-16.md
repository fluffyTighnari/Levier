## 1. 目标

实现 PostgreSQL `Store.Enqueue` / `EnqueueTx`：同 `(run_id, task_type)` 活跃任务唯一，重复入队返回既有任务，并支持与 Run 创建同一事务。不实现 Claim/Lease（P2-17）。

## 3. 关键决策

- 依赖 `run_tasks` 的部分唯一索引 `(run_id, task_type) WHERE status IN ('PENDING','LEASED')`。
- `INSERT ... ON CONFLICT ... DO NOTHING RETURNING` 判断冲突；无返回时查询既有活跃任务。
- 若冲突任务在 insert/select 之间消失，重试一次；仍失败返回明确错误。
- `normalizeForEnqueue` 统一补 ULID/状态/默认 attempts/时间戳，并拒绝非 PENDING、attempt>0、预置 lease。
- `EnqueueTx` 接受 `pgx.Tx`，Run 创建 + task 入队可原子提交或回滚。
- `payload` 使用 JSONB；nil payload 归一为 `{}`。

- 同事务回滚：Run 与 Task 都不存在。
- 非 PENDING/attempt>0/预置 lease/非法 type：本地拒绝。
