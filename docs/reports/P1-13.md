## 3. 关键决策

- proto 是唯一事实来源；`DESIGN.md` 为镜像。
- v1 只允许新增字段/消息/enum value；删除、改名、改类型、复用 field number 必须升 v2。
- 黄金样本和文档使用 proto 原字段名（snake_case）。
- proto3 JSON 的 int64 编码为字符串；fixture 已按此规则冻结。
- Go 用 `protojson` + `Validate`；Python 用 `json_format`，两侧都对同一份 JSON 做 round-trip。
- `buf breaking` 以 `main` 为基线，`make contract-check` 同时跑 Go/Python/buf。
- 本地 Python 3.12 使用 `uv` 创建 `.venv312`；CI 使用 Python 3.12。
