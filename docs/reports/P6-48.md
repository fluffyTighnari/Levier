## 3. 过滤

候选必须满足：

- `Healthy=true`
- runtime type 匹配（`UNSPECIFIED` 通配）
- strategy 在 `supported_strategies`
- 请求 labels 是 daemon labels 的子集
- `RunningCount < MaxConcurrentRuns`

满载 daemon 不参与分配。

## 4. 排序

- 默认 least-loaded：

```text
running / max_concurrent_runs
```

- 比例相同按 `daemon_id` 稳定排序。

## 5. longterm 粘滞

Control 对 `runtime=longterm`：

- 把 `run.assigned_daemon_id` 作为 `StickyDaemonID`
- 如果 sticky daemon 仍满足过滤条件：
  - 直接选择它，即使负载更高
- 如果 sticky：
  - 满载
  - 不健康
  - runtime/strategy/labels 不匹配
  - 不存在
  - 则回退到 least-loaded

normal run 不使用 sticky。

## 6. 入口

`cmd/middleware`：

```go
Scheduler: control.NewHubScheduler(hub)
```

`HubScheduler` 从 `Hub.List()` 取快照，转换为 `Candidate` 后调用纯函数 `Select`。
