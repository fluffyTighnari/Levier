## 3. 关键决策

- 所有 builder 默认生成 ULID `msg_id` 和 UTC 毫秒时间戳；测试可覆盖。
- `NewRun` 负责设置 `run_id/attempt/lease_epoch`；`NewResponse` 自动复制请求 scope 并设置 `correlation_id`。
- `Validate` 统一返回 `BAD_ENVELOPE` 包装错误；底层原因保留，可用 `errors.Is/As` 检查。
- 仅持久化事件消耗 seq；ephemeral 必须 `seq=0` 且 source=`daemon`。
- MW 事件 seq 必须 `>= MWSeqBase (1<<62)`；daemon 事件必须 `< MWSeqBase`。
- TaskAck、ToolCallResult 必须有 correlation_id。
- `TaskAssign` 要求 `attempt>=1`、`lease_epoch>=1`、model/timeouts 完整；工具名和 MCP server 名不得重复。
- 默认 envelope 上限 16 MiB，与 gRPC 配置一致。
