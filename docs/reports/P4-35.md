## 1. 目标

验证真实 Middleware + 真实 Python Harness 的 echo 全链路：

```text
HTTP POST /runs
  → RunStore
  → workflow RUN_DISPATCH
  → Control
  → DaemonHub
  → Harness echo
  → TaskAck
  → RUN_STATUS / MESSAGE_COMPLETED
  → RunStore run_events
  → HTTP GET events
```

验收：

- seq 连续
- 终态正确
- 事件可回放

## 3. E2E 脚本

启动：

- `bin/middleware -config config.example.yaml`
- `harness/.venv/bin/python -m middleware_harness --config harness/config.example.yaml`

等待：

- HTTP `/healthz`
- Harness 连接到 gRPC `:9090`
- Control worker 开始 claim

提交：

```json
{
  "app_id": "app-e2e",
  "runtime": "normal",
  "strategy": {"name": "echo"},
  "input": [{"role": "user", "content": "hello e2e"}],
  "model": {"provider": "anthropic", "model": "claude-test"},
  "timeouts": {"run_ms": 10000, "tool_ms": 5000}
}
```

轮询 Run 状态，直到 `completed` 或超时。

校验：

- 事件 seq = `[1, 2, 3]`
- 类型 = `RUN_STATUS`、`MESSAGE_COMPLETED`、`RUN_STATUS`
- 第一条 status=`running`
- 第三条 status=`completed`
- `next_attempt=1`、`next_seq=3`
