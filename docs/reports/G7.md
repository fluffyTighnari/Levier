## 9. G7 结论

**功能 Gate 通过。**

已知限制：

- ws_token 与 single-flight 缓存是单进程状态；多实例需共享存储/粘滞路由。
- 工具配置在首次执行时校验，注册时只校验 JSON 语法。
- HTTP/webhook 允许访问任意 http(s) 地址，生产需 egress 白名单。
- 没有执行器/缓存指标。
- REST 仍以 legacy bearer 作为兼容路径，可跨 App 访问；生产应只配置 App key/Admin token。
- WS 没有服务端 ping/空闲超时与帧大小限制。
- `run_completed` 可能重复，客户端需按 run 幂等。
- 对账审计、限流、CORS 留 P8。
