## 3. 关键决策

- 进程崩溃用“Claim 后不 Ack + lease 过期 + ReapExpired”模拟，不真实重启 PostgreSQL。
- 延迟任务通过修改 `available_at` 模拟时钟跳变。
- Pool 测试用任务 ID map 断言每个任务只执行一次。
- 取消后任务不得再被 Claim/执行。
- 连接池耗尽通过占满 `MaxConns` 后带超时 Claim 测试。
- Nack 与 Cancel 竞态允许两种合法结果：
  1. Nack 先回转 PENDING，Cancel 随后取消 → Nack 成功 + CANCELLED。
  2. Cancel 先赢 → Nack `ErrLeaseLost`。
- 使用 `go test -race` 验证 worker/pool 并发。

## 4. 验证

```sh
MIDDLEWARE_TEST_POSTGRES=1 go test -count=1 -v -timeout 180s ./internal/workflow
MIDDLEWARE_TEST_POSTGRES=1 go test -race -count=1 -timeout 240s ./internal/workflow
make lint
make test
make build
make proto-check
```

结果：

- `TestDelayedTaskNotClaimedEarly`：未来任务不被提前 Claim；修改 available_at 后可 Claim。
- `TestCrashRecoveryAfterLeaseExpiry`：旧 lease 失效，新 worker attempt=2、token 递增，最终 DONE。
- `TestPoolProcessesEachTaskOnce`：4 worker 处理 20 任务，每任务一次。
- `TestCancelledTaskIsNotExecuted`：取消后 ProcessOne 返回 false，handler 未调用。
- `TestCancelNackRace`：5 轮合法竞态结果均符合预期。
- `TestConnectionPoolExhaustion`：连接池耗尽时 Claim 超时，而非 ErrNoTask。
- `-race`：通过。
- 真实 PostgreSQL 16.15 通过；默认 `make test` 跳过 DB 测试。
- `make lint/test/build/proto-check` 全绿。
