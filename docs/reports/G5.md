## 4. 注册 API 样例

```sh
curl -X POST http://127.0.0.1:8080/admin/apps \
  -H 'Authorization: Bearer admin-change-me' \
  -H 'Content-Type: application/json' \
  -d '{"name":"app-a","multiagent":true}'
```

返回一次性 `api_key`。

App 更新可携带：

```json
{
  "name": "app-a",
  "tools": [{"name":"search","schema":{"type":"object"}}],
  "mcp_refs": ["github"]
}
```

## 5. 密钥脱敏

- API key 只返回一次，库存 SHA-256 hash。
- MCP 密钥通过 `${secret:*}` 解析后只在 TaskAssign/Runtime 内存使用。
- 日志不打印 `TaskAssign.mcp_bindings`。
- G5 材料快照中密钥写为 `***`。
