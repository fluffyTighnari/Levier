## 3. API

### POST /admin/apps

Admin token 鉴权：

```http
Authorization: Bearer <admin_token>
```

请求：

```json
{"name":"app-a","multiagent":true}
```

- 首次创建：`201`，返回 `api_key` 明文一次。
- 重复 name：`200`，返回已有 App，`api_key` 为空。
- 明文 key 不落库，只存 SHA-256 hash。

### POST /api/v1/apps

App API key 鉴权，更新自身：

```json
{"name":"new-name","multiagent":true}
```

- 只能更新 API key 对应的 App。
- name 冲突返回 `409`。

### GET /api/v1/apps/{app_id}

- Admin 可查任意 App。
- App key 只能查自己，否则 `404`。

### POST /admin/apps/{app_id}/rotate-key

Admin token 鉴权。

- 生成新 key。
- 旧 key 立即失效。
- 新 key 明文只返回一次。

### POST /api/v1/runs

支持两种身份：

1. App API key：
   - 从 key 解析 app_id。
   - 请求体 `app_id` 可省略。
   - 如果请求体 app_id 与 key 不一致 → `403`。
2. Admin / 本地 legacy token：
   - 请求体必须带 app_id（兼容 P4）。

## 4. API key

生成：

```text
mw_<32 random bytes base64url>
```

存储：

```text
SHA-256 hex
```

- `apps.api_key_hash` 加唯一索引，鉴权查询走索引。
- 明文只在创建/rotate 时返回。
- 不写日志。

## 5. 重复 name 幂等

`RegisterApp`：

```sql
INSERT ... ON CONFLICT (name) DO NOTHING
```

无插入时按 name 查询已有 App：

- 返回同一 app_id
- 不返回新 key
- `created=false`

| 没有 App disable/delete API | 只能改 status 字段 | P5-42/P7 |
