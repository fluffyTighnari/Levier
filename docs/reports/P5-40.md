## 3. ListEvents

```go
ListEvents(ctx, runID, afterAttempt, afterSeq, limit)
```

规则：

- `afterAttempt` / `afterSeq` 不能为负
- limit：
  - 缺省 100
  - 最大 1000
- 顺序：

```sql
ORDER BY attempt, seq
```

- 游标：

```sql
attempt > after_attempt
OR (attempt = after_attempt AND seq > after_seq)
```

这样分页不会重复，也不会漏掉后续 attempt。

## 4. Session 聚合

新增：

```go
ListSessionEvents(ctx, sessionID, afterAttempt, afterSeq, limit)
```

查询：

```sql
SELECT e.*
FROM run_events e
JOIN runs r ON r.run_id = e.run_id
WHERE r.session_id = ?
  AND (e.attempt > ? OR (e.attempt = ? AND e.seq > ?))
ORDER BY r.created_at, r.run_id, e.attempt, e.seq
LIMIT ?
```

稳定顺序：

1. Run 创建时间
2. Run ID（同一时间戳的 tie-breaker）
3. Run attempt
4. Event seq

限制：

- session_id 必填
- limit 同样默认 100、最大 1000
