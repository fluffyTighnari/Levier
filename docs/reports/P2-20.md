## 3. 关键决策

- Worker 一次只 Claim 一个任务；Pool 通过多 worker 实现并发。
- Handler 返回 nil → Ack。
- `Permanent` → Fail + DeadLetter。
- `RetryAfter` → 指定延迟 Nack；其他错误 → `Backoff(attempt, base, max)` Nack。
- Nack 后若 `task.Attempt >= MaxAttempts`，调用 DeadLetter。
- Handler panic 被 recover 为普通错误，走 Nack，不会杀进程。
- 执行期间按 `HeartbeatInterval` 调用 `Extend`；续租失败取消 Handler context。
- `Stop` 先停止 Claim、等待当前 Handler；超过 `ShutdownTimeout` 才取消 Handler context。
- Worker/Pool 不可重启；owner 使用 `pool-worker-N`。

## 4. 验证

```sh
MIDDLEWARE_TEST_POSTGRES=1 go test -count=1 -v -timeout 120s ./internal/workflow
make lint
make test
make build
make proto-check
```

结果：

- Ack 路径：任务 DONE。
- Nack 路径：任务回到 PENDING，attempt 保留。
- Permanent：任务 DEAD，DeadLetter 回调收到任务。
- Panic：进程不退出，任务按重试进入 PENDING。
- 慢 Handler：heartbeat 续租，期间 ReapExpired 回收数为 0，最终 DONE。
- Stop：Handler 运行中 Stop 等待，放行后 Stop 返回，任务 DONE。
- Pool：4 worker 并发处理 8 个任务，全部 DONE。
- 真实 PostgreSQL 16.15 通过；默认 `make test` 跳过 DB 测试。
- `make lint/test/build/proto-check` 全绿。
