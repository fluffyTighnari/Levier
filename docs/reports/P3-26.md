## 1. 目标

建立策略接口，实现第一个 echo 策略，并让 RunManager 默认使用它。echo 不调用 LLM，只回显最后一条用户消息，用于验证 M1 事件序列。

## 3. 关键决策

- `Strategy` 是 `name + run(ctx)` 协议。
- `EchoStrategy` 支持两种调用方式：
  - `await strategy.run(ctx)`
  - `await strategy(ctx)`（通过 `__call__`，兼容 RunManager 的 Runner 协议）
- echo 内容取 `TaskAssign.input[-1].content`；为空时使用 `echo`。
- 事件顺序：
  1. RunManager 发 `RUN_STATUS running`（seq=1）
  2. EchoStrategy 发 `MESSAGE_COMPLETED`（seq=2）
  3. RunManager 发 `RUN_STATUS completed`（seq=3）
- `MESSAGE_COMPLETED` data：`message_id`、`role=assistant`、`content`。
- 当前 `__main__` 只把 `echo` 暴露为支持策略；`react` 从 P3-27 开始接。
