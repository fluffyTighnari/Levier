# I1 执行清单：单机稳定版

> 来源：`docs/INDUSTRIAL_ROADMAP.md`  
> 状态：Draft  
> 说明：本清单只拆 I1 的执行项和验收，不重新定义路线图决策。任何范围变化先改权威路线图。

## 1. 进入条件

- [ ] `docs/INDUSTRIAL_ROADMAP.md` 保持 Accepted。
- [ ] I1 的七项基础决策没有未决变更。
- [ ] 当前 normal Runtime 的 CI 和 smoke 测试通过。
- [ ] 明确 I1 不引入 Redis、NATS、多定义 Runtime Host、Sandbox 生产化和 Longterm 生产化。

## 2. 契约基线

- [ ] 固化 Run 生命周期语义：当前状态、终态、重试和取消。
- [ ] 固化事件语义：固定事件、持久事件、ephemeral 事件和事件回放。
- [ ] 固化 Runtime 能力声明语义：协议版本、能力、并发和资源需求。
- [ ] 固化 App Bridge v2 的目标语义：并发、进度、取消、幂等和连接租约；I1 只冻结，不实现。
- [ ] 固化软多租户边界：哪些对象、路径和指标必须带租户归属。
- [ ] 固化协议兼容原则：只增量演进，不删除 v1 语义。
- [ ] 所有契约文档与路线图保持一致。

## 3. 软多租户

- [ ] Run、App、Session、Runtime 注册等核心对象可追踪租户归属。
- [ ] 认证路径能识别租户边界。
- [ ] 查询路径默认按租户过滤。
- [ ] 日志、指标和审计包含租户维度。
- [ ] 配额接口和默认值存在，但 I1 不要求执行完整配额。
- [ ] 跨租户访问被明确拒绝。
- [ ] 不引入每租户独立数据库、独立集群或完整计费。

## 4. Runtime 进程模型

- [ ] 一个 Runtime 进程只承载一个 Runtime 定义。
- [ ] 默认部署为单实例。
- [ ] 同一定义的多副本作为可选部署方式，不改变单进程单定义原则。
- [ ] 不引入单进程多定义的 Runtime Host。
- [ ] 不把 sandbox 或 longterm 做成半成品。
- [ ] React Runtime 继续作为参考实现，Echo Runtime 继续作为最小 conformance。

## 5. 单一状态源

- [ ] PostgreSQL 继续作为 Run、事件、任务和租约的事实来源。
- [ ] I1 不引入 Redis 或 NATS。
- [ ] 跨实例通知只作为唤醒信号，不作为状态本身。
- [ ] 事件回放以 Event Store 为准。
- [ ] 所有重试和恢复路径不依赖进程内缓存作为最终状态。
- [ ] 不出现“数据库 + 缓存 + 消息”多套状态源。

## 6. 当前 normal Runtime 稳定性

- [ ] normal Runtime 的启动、停止、重连和取消行为有明确验收。
- [ ] Run 分配、重试、超时和终态转换有明确验收。
- [ ] 事件顺序、去重和断线回放有明确验收。
- [ ] 工具调用超时、失败和 App 断线行为有明确验收。
- [ ] 现有 Python App 写法保持不变。
- [ ] 现有最小 Runtime 写法保持不变。

## 7. 运维与兼容

- [ ] I1 不新增生产基础设施。
- [ ] 数据库迁移保持向后兼容。
- [ ] 备份、恢复和升级流程可执行。
- [ ] 配置、日志和指标足以定位 Run、App、Runtime 和租户问题。
- [ ] 发布流程支持回滚。
- [ ] 文档中不存在与权威路线图冲突的旧决策。

## 8. 退出条件

- [ ] 当前 normal Runtime 功能稳定。
- [ ] 没有新增基础设施。
- [ ] Run、App、Session、日志和指标可按租户追踪。
- [ ] I1 契约文档与权威路线图一致。
- [ ] I1 只冻结 I2 契约，没有提前实现 I2 能力。
- [ ] I1 范围内的测试、smoke 和回归通过。

## 9. I1 明确不做

- 不实现 Runtime Driver。
- 不实现自定义事件。
- 不实现 checkpoint / resume 生产化。
- 不实现 LangGraph。
- 不实现 App Bridge v2 的并发、进度、取消和连接租约。
- 不拆 Runtime Gateway 或 App Gateway。
- 不引入 Redis、NATS 或对象存储。
- 不做 Sandbox、Longterm 生产化和物理租户隔离。

## 10. 完成标记

- [ ] 代码、配置、文档和测试进入 I1 完成状态。
- [ ] 权威路线图中的 I1 退出条件全部满足。
- [ ] 下一版本 I2 的范围和依赖经过确认。
- [ ] 本清单归档，不继续承载新决策。
