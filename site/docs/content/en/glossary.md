## 1. Roles

| Term | Meaning |
|---|---|
| **App** | The process that holds business state, registers tools and executes handlers |
| **Levier** | The control plane: authentication, scheduling, run status, events, model/MCP catalogue |
| **Runtime** | Executes `run(ctx)` and decides how the model and tools are used |
| **MCP Runtime** | A standalone process that connects to MCP servers and is shared by runtimes |
| **Run** | A single execution, from submission to terminal state |

## 2. Configuration

| Term | Meaning |
|---|---|
| **User profile** | User-level configuration that stores locators such as server, credential paths and runtime |
| **`.levier.json`** | Project-level configuration, generated by `levier init` |
| **App key** | The API key the App uses to connect to Levier |
| **admin token** | Token for administrative operations |
| **runtime token** | Token the Runtime uses to connect to the control plane |
| **managed secret** | Model key file managed by the control plane |
| **`mcp_ref`** | MCP server reference declared by the App |
| **`allowed_tools`** | Tool allowlist enforced by the MCP Runtime |

## 3. Execution

| Term | Meaning |
|---|---|
| **`run(ctx)`** | The Runtime's only entry point function |
| **Context** | The input, model, tools, timeout and cancellation state of this run |
| **Toolbox** | A unified view of local + MCP tools |
| **`ctx.chat`** | Calls the model with this run's model configuration |
| **`ctx.invoke_all`** | Executes every tool the model requested, routing local/MCP automatically |
| **checkpoint** | A state snapshot saved by the Runtime |
| **terminal** | `completed` / `failed` / `cancelled` / `timeout` |

## 4. Legacy terms

These are internal/legacy concepts and are no longer part of the integration contract:

```text
provider                 consolidated into model
daemon                   corresponds to a Runtime instance
secret_ref               provider-internal reference
ws_token                 short-lived App WebSocket token
lease_epoch              Runtime lease version
event seq / ack          event sequence number and acknowledgement
local_tool_call/result   App tool frames
RuntimeChannel           Runtime gRPC connection
Hello / Heartbeat        Runtime handshake and heartbeat
```

Consult the architecture or protocol documents when you need low-level troubleshooting.

## 5. Choosing

```text
Business functions only            App
Control how the Agent runs         Runtime
Link verification only             echo1
Standard model + tool loop         react1
```
