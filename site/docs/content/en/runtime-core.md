> [!NOTE]
> The local stack already includes `react1` and `echo1` by default. Write a Runtime only when you need custom execution logic.

## 1. When you need a Runtime

```text
Built-in react1 covers the usual ReAct loop   → no need to write one
Want to control prompt, tool order, loop      → write your own Runtime
Just want to verify the chain                 → use echo1
```

## 2. runtime init

```sh
levier runtime init
```

> [!OUTPUT]
> ```text
> created runtime.py
> start it with: levier runtime start
> ```

`./runtime.py` is generated by default. Keeping the Runtime in its own directory is recommended:

```text
my-runtime/
  runtime.py
  pyproject.toml
```

## 3. run(ctx)

```python
from levier import Context, Runtime


async def run(ctx: Context) -> str:
    tools = await ctx.toolbox()

    # Decide how the prompt is assembled
    reply = await ctx.chat(ctx.input, tools=tools)

    # Invoke every tool the model requested in one line; local/MCP routing is automatic
    await ctx.invoke_all(reply, toolbox=tools)

    await ctx.reply(reply.content or "done")
    return "completed"


if __name__ == "__main__":
    Runtime.start(run)
```

The returned string is the terminal state: usually `completed` / `failed`. `ctx.error` is also available.

## 4. runtime start

```sh
levier runtime start
```

> [!OUTPUT]
> ```text
> runtime: my-runtime
> file:    /path/to/runtime.py
> server:  127.0.0.1:9090
> ```

By default, the runtime name, gRPC address and token are read from the profile.

## 5. Error handling

Uncaught exceptions automatically become:

```text
ERROR event
Run failed
```

Explicit errors:

```python
await ctx.error("MY_ERROR", "something failed", retryable=False)
```

Tool errors:

```python
result = await ctx.call_tool("search", {"query": "levier"})
if not result.ok:
    await ctx.error(result.error_code, result.error_message)
```

## 6. Not needed

```text
runtime.yaml
runtime_token
daemon id
gRPC / protobuf
event seq / lease_epoch / ack
MCP client
```

These are handled by the SDK. See the following pages when you need to override them.
