> [!NOTE]
> 读完之后：用一句话说明读者能做什么。不要写「本文介绍了……」。

## 1. 这一页解决什么

用两三句话说清适用场景，以及**不需要**先读什么。

## 2. 前置条件

- 需要哪些服务、凭据或版本。
- 不需要什么，避免读者多装东西。

## 3. 步骤

每一步都给可复制的命令，并说明为什么需要这一步。

```sh
# 一条最小可运行命令
```

> [!OUTPUT]
> 把关键行写出来，不要让读者猜。

> [!FAIL]
> 先检查什么，再看哪条日志。

## 4. 验证

给一个可以独立确认成功的检查命令或事件。

## 5. 常见问题

| 现象 | 先检查 | 动作 |
|---|---|---|
| 命令返回 401 | App key / Admin token | 重新创建凭据 |
| Run 一直 queued | daemon 是否在线 | 看 runtime 日志 |
